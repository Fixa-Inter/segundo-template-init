## ✨ Visão geral

O repositório não contém uma aplicação própria. Projetos criados a partir deste template devem substituir a documentação inicial pelas informações específicas do novo serviço.

## 🚀 Funcionalidades

- Estrutura inicial para novos repositórios
- README de apresentação do projeto
- Licença padrão da organização
- Integração com workflows reutilizáveis
- Criação automática de releases na branch principal
- Padronização dos repositórios da Fixa-Inter

## 🧰 Tecnologias
